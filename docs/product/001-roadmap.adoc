= Promoting Roadmap

== Milestone 1

* Promotion.
* Rule.
* ApplicationMethod.
* Fixed/percentage methods.
* Deterministic explanations.

== Milestone 2

* Coupon lifecycle.
* Limits and restrictions.
* Stacking, priority, and exclusivity.

== Milestone 3

* Campaigns, windows, and budgets.
* Grouped activation, pause, and resume.

== Milestone 4

* Buy-X-Get-Y.
* Free shipping.
* Pricing/Carting/Ordering integration.

== Milestone 5

* Coupon issuance book and normalized uniqueness.
* Issue/deactivate lifecycle.
* Customer-bound coupons.
* Coupon validity windows with explicit evaluation time.

== Milestone 6

* Immutable promotion catalog.
* Promotion-id uniqueness.
* Deterministic eligible selection.
* Preserve per-promotion evaluation results for auditability.

== Milestone 7

* Coupon-code lookup.
* Coupon validation before promotion lookup.
* Coupon-to-promotion catalog resolution.
* Combined coupon and promotion eligibility explanation.

== Milestone 8

* Resolve coupon to linked promotion.
* Apply promotion before redemption.
* Record redemption only after successful application.
* Preserve idempotent replay without duplicate redemption.

== Milestone 9

* Validate campaign availability before member selection.
* Resolve campaign promotion IDs through the promotion catalog.
* Preserve missing-member audit reasons.
* Select eligible campaign promotions deterministically.

== Milestone 10

* Resolve and apply campaign-scoped promotions.
* Enforce remaining campaign budget before spend.
* Record discount amount as campaign spend only after successful application.
* Reject zero-discount and budget-overflow applications without mutating campaign state.

== Milestone 11

* Distinguish automatic and coupon-required promotion activation.
* Exclude coupon-required promotions from automatic catalog selection.
* Preserve explicit audit reason when a coupon is required.
* Allow coupon resolution to activate coupon-required promotions.

== Milestone 12

* Build a read-only checkout promotion plan.
* Combine automatic and optional coupon promotions before stacking resolution.
* Resolve monetary discounts under one priority/exclusivity policy.
* Produce typed non-price benefits only for promotions reached by resolution.
* Keep cart/order/campaign/redemption state immutable during planning.

== Milestone 13

* Apply the unified checkout promotion plan.
* Record coupon redemption only when the coupon promotion actually participates in resolution.
* Preserve idempotent same-order replay at usage limits.
* Leave promotion-owned ledger state unchanged when a coupon is invalid or displaced by exclusivity.

== Milestone 14

* Reverse checkout coupon redemption by coupon/customer/order identity.
* Preserve idempotent reversal no-op semantics.
* Leave Cart and Order state outside Promoting ownership.
* Surface missing-coupon reversal as an auditable no-op result.

== Milestone 15

* Track campaign spend by campaign/order identity in an immutable ledger.
* Keep campaign aggregate spend synchronized with active ledger spend.
* Preserve idempotent same-order campaign application replay.
* Reverse campaign spend atomically for cancellation/refund flows.
* Reject aggregate/ledger drift instead of silently repairing it.

== Milestone 16

* Add explicit campaign-only promotion activation.
* Exclude campaign-only promotions from ordinary automatic checkout selection.
* Allow automatic and campaign-only promotions inside campaign context.
* Keep coupon-only promotions isolated from campaign selection.
