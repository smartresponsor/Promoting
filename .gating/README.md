# Promoting Gating Artifacts

This directory is an artifact-only consumer surface for `gating/gate`.

Allowed generated state:

- reports and evidence;
- cache and checksum data;
- generated artifacts.

Normative Gating policy, executable rules, configuration, and owner source code remain in the `Gating` repository or canonical Symfony configuration surfaces. Do not materialize or copy the Gating engine into this directory.
